# CyberLabs

Notes, experiments and write-ups from my cybersecurity labs.

This repository is where I keep track of the machines I've completed, the techniques I've practiced and the things I've learned along the way.

The focus is mainly on penetration testing, network security and vulnerability research.

## Labs

| Platform | Description |
|---|---|
| [TryHackMe](TryHackMe/) | Rooms and lab notes |
| [Personal Labs](OwnLabs/) | Wireless security and personal experiments |

More platforms and labs will be added over time.

## Structure

- **TryHackMe/** — Rooms and lab notes
- **HackTheBox/** — Machines and challenges
- **ThePwnLab/** — CTF challenges
- **OwnLabs/** — Personal experiments and controlled testing environments
- **Tools/** — Scripts and utilities

## Documentation

Depending on the lab, the notes may include:

- Environment and tools used
- Reconnaissance and enumeration
- Findings and technical analysis
- Commands and relevant output
- Exploitation and privilege escalation, where permitted
- Mitigations and lessons learned

Not every attempt is successful. I document failed approaches too, especially when they help explain why something didn't work.
